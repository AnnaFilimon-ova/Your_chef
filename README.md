# 🍱 Your Chef TG Bot

## 📌 Description
Telegram Bot that gives you a random dish along with its recipe. Simply click the button to receive a random meal, its ingredients, and cooking instructions.

## ✈️ How to use
- You click button "Meal"
- You take dish, ingredients and recipe
- You can add ingredient to the black list

## 🚀 Features
- Random dish
- BlackList 
- Possibility edit BlackList

## ⚙️ Installation
```bash
git clone <https://github.com/AnnaFilimon-ova/Your_chef.git>
cd Your_chef
source venv/bin/activate
python main.py
```

## 🛠 Tech Stack
- Python 
- Telebot
